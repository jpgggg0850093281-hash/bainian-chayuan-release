# 百年茶緣｜徽章素材庫

每章使用獨立資料夾。完成的徽章包含以下檔案：

```text
chNN-name/
  frames/000.png
  frames/060.png
  frames/120.png
  frames/180.png
  frames/240.png
  frames/300.png
  sprite.png
  front.png
  preview.mp4
```

## 分鏡與像素規格

- 每 60° 一格，依序為 0°、60°、120°、180°、240°、300°。沿垂直軸左右旋轉。240° 是 120° 的左右鏡像。300° 沿用 60° 的鏡像輪廓，正面文字及圖案須恢復正確方向。
- 第一章原圖為 2172 × 724 像素，共四格。因此單格尺寸定為 **543 × 724 像素**，六格橫排的圖集為 **3258 × 724 像素**。同一徽章的比例、中心點與底部基準線一致。新素材使用透明背景，Alpha 只允許 0 或 255。
- 採像素風、一像素深色描邊、兩到三階明暗。作畫及顯示時對齊遊戲的 480 × 270 像素格，使用最近鄰縮放，並以第一章紀念幣與第三章火候筆記為視覺參考。
- 第三章原始六格置中留邊至標準尺寸，保留原圖像素比例，並將邊緣透明度轉為二值。

### 第一章舊版四格

現有 [茶寮新手圖集](../tea-coin-frames.png) 保留原位。典藏版依既有順序裁成斜面、側緣、背面、正面，保留嵌在圖裡的深綠場景。斜面精確角度無法從原圖確定，索引用 `null`，檔名為 `oblique.png`。其餘依畫面標為 90°、180°、0°。圖集保留四格原順序，`front.png` 從最後一格取出。遊戲若讀取此徽章，須使用索引內的實際格數與正面位置。

## 領取動畫與影片

- 領取時兩圈約 1.8 秒，使用 ease-out 減速後停在 0°，最後輕輕回彈。遊戲在偏好減少動態效果的系統上只淡入正面。
- 預覽用 H.264 MP4，固定 30 fps、`yuv420p`，以 `-movflags +faststart` 將索引放到檔案前端。背景為 `#12271e`，徽章置中，兩圈後正面保留約 1 秒。影片尺寸為 544 × 724 像素，補一欄供 4:2:0 編碼使用。
- 第 2、4、5、6、7 章索引狀態為 `todo`，資料夾已預留。第一章與第三章標為 `ready`。

## 新增與更新

1. 把六張單格圖放進該章的 `frames/` 並用角度命名。
2. 從儲存庫根目錄執行 `npm ci`，再執行 `npm run badge:build -- <章節資料夾名>`。工具產生 `sprite.png`、`front.png`，並將 `badges.json` 同步成 `badges.js`。系統 PATH 有 FFmpeg 時也會產生 `preview.mp4`。缺少 FFmpeg 時會顯示提示並保留現有影片。
3. 更新 `badges.json` 的獲得說明等資料，素材及影片齊全後把該章標成 `ready`。
4. 再執行一次該章建置，然後執行 `npm run badge:check`。檢查會比對雙索引、單格尺寸和透明度、生成圖集及正面的像素，並確認影片存在。

以 `file://` 開啟時，可用一般 `<script src="assets/badges/badges.js"></script>` 取用 `window.BAINIAN_BADGES`。索引路徑以遊戲根目錄為基準。讀取方可依 `status` 判斷是否顯示徽章，並從 `angles` 定位 0° 的格號。
