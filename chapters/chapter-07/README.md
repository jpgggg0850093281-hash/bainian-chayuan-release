# 第七章祭典扭蛋機

從第七章點「前往祭典扭蛋機」，或直接開啟 `gacha.html`。正式模式讀取七個章節的完成紀錄，並把抽中的獎品 ID 記在 `bainian-gacha-result`。使用網站時，章節和扭蛋頁面須在同一來源，才能共用進度。直接用 `file://` 預覽時，瀏覽器可能會隔離各頁面的本機儲存，可用 `gacha.html?dev=1` 從頭測試。

開發模式可以加上 `&step=fusion`、`&step=coin`、`&step=insert`、`&step=capsule` 或 `&step=prize`。測試抽獎不寫入正式結果。正式模式在轉動把手、抽出扭蛋時保存結果，重開頁面可從「查看獎品」取回。

正式徽章從 `assets/badges/badges.js` 讀取。若索引或某枚分鏡尚未部署，畫面會使用對應的章節圖案。獎品與權重可在 `gacha.js` 的 `PRIZES` 調整。
